# Korea Commercial District Consumer Analysis (한국 상권 소비자 분석)

한국 외식업 창업을 위한 상권 소비자 심층 분석 프레임워크. 유동인구, 연령별 소비패턴, 경쟁매장, 매출 가능성, 상권 성장성, 외식 트렌드, 배달 선호도를 종합 분석한다.

## 분석 원칙

1. **최신 데이터 우선:** 반드시 최신 데이터 소스를 참조한다. 1년 이상 된 데이터는 `[주의: YYYY년 데이터]`로 표시하고 현재 상황과 차이가 있을 수 있음을 명시한다.
2. **한국 데이터 우선:** 해외 벤치마크보다 한국 시장 데이터를 우선 적용한다. 소상공인시장진흥공단, 나이스지니, KB부동산, 통계청 데이터를 기본으로 한다.
3. **동네 단위 분석:** 구 단위가 아닌 동/블록 단위로 분석한다. 같은 성동구라도 성수동1가와 성수동2가는 완전히 다른 상권이다.
4. **정보 업데이트 프로토콜:** 분석 시점을 명시하고, 사용자에게 주기적 재분석을 권고한다.

## Data Sources (데이터 소스)

### 필수 참조 소스

| Source | What It Provides | Access Method |
|--------|-----------------|---------------|
| **소상공인시장진흥공단 상권분석** (sg.sbiz.or.kr) | 유동인구, 매출추정, 업종밀집도 | Web search for latest data |
| **나이스지니 (NICE GINI)** | 카드매출 데이터, 업종별 매출 추이 | Web search for reports |
| **서울 열린데이터광장** (data.seoul.go.kr) | 생활인구, 상권변화지표 | Web search for latest datasets |
| **통계청 KOSIS** | 인구통계, 가구소득, 소비지출 | Web search for census data |
| **네이버 데이터랩** (datalab.naver.com) | 검색 트렌드, 지역별 관심도 | Web search for trend data |
| **배달앱 리뷰/순위** | 실시간 배달 트렌드, 인기 메뉴 | Web search for current rankings |
| **카카오맵/네이버지도** | 경쟁매장 현황, 리뷰 수, 평점 | Web search for competitor data |

### 데이터 수집 지시

분석 수행 시, 반드시 web search를 활용하여 해당 동네의 최신 정보를 수집한다:
- `"{동네명} 상권분석 2025"` 또는 현재 연도
- `"{동네명} 유동인구 통계"`
- `"{동네명} 외식업 트렌드"`
- `"{동네명} 신규 오픈 맛집"`
- `"{동네명} 배달 인기 음식"`

**업데이트 주기 권고:** 상권 데이터는 분기별(3개월) 재분석을 권고한다. 대규모 개발(재개발, 지하철 개통)이 있으면 즉시 재분석한다.

## 1. 유동인구 분석 (Foot Traffic Analysis)

### 분석 프레임워크

| Dimension | Metrics | Data Source |
|-----------|---------|-------------|
| **총 유동인구** | 일평균/시간대별 통행량 | 서울 생활인구 데이터, 소상공인 상권분석 |
| **시간대 분포** | 아침/점심/저녁/심야 비중 | 현장 카운트 + 공공데이터 |
| **요일 패턴** | 평일 vs 주말 차이 | KT/SKT 유동인구 리포트 |
| **계절 변동** | 월별 변동폭 | 연간 추이 데이터 |
| **이동 목적** | 출퇴근/쇼핑/여가/관광 | 생활인구 유형 분류 |

### 시간대별 기회 매핑

| Time Slot | Target Customer | F&B Opportunity |
|-----------|----------------|-----------------|
| 07-09 | 출근족 | 커피, 간편식, 토스트 |
| 11-14 | 직장인, 지역주민 | 점심 한식, 비빔밥, 국밥 |
| 14-17 | 카페족, 미팅 | 카페, 디저트, 브런치 |
| 17-21 | 퇴근족, 약속 | 저녁 식사, 회식, 데이트 |
| 21-02 | 야식, 2차 | 술집, 안주, 배달 |

### 유동인구 품질 평가

단순 수량이 아닌 "돈을 쓸 사람"인지 평가:

- **체류형 vs 통과형:** 걸어서 지나가는 사람 vs 해당 블록에서 시간을 보내는 사람
- **목적성 방문 vs 우연 방문:** 일부러 찾아오는 곳 vs 지나가다 들르는 곳
- **소비 여력:** 연령대, 직업군 기반 평균 외식 지출 추정

## 4. 경쟁매장 분석 (Competitor Analysis)

### 경쟁 매핑 프레임워크

반경 300m 내 모든 동일/유사 업종을 매핑:

| Dimension | What to Measure | Red Flag |
|-----------|----------------|----------|
| **직접경쟁** | 동일 메뉴/가격대/타겟 | 3개 이상이면 포화 |
| **간접경쟁** | 같은 식사 시간대 경쟁 | 대형 프랜차이즈 밀집 |
| **배달경쟁** | 배달앱 내 동일 카테고리 | 리뷰 1,000+ 강자 존재 |
| **대체재** | 편의점, 구내식당, 도시락 | 기업 구내식당 있으면 점심 시장 축소 |

### 경쟁자 분석 체크리스트

각 경쟁매장별:
1. **매출 추정:** 배달앱 리뷰 수 x 평균 객단가 x 3-5배 = 월매출 추정
2. **강점/약점:** 메뉴, 가격, 서비스, 인테리어, 위치
3. **리뷰 분석:** 네이버/카카오/배달앱 평점 + 최근 리뷰 키워드
4. **운영 시간:** 영업시간, 정기휴무, 라스트오더
5. **포지셔닝 갭:** 경쟁자가 커버하지 못하는 가격대/메뉴/시간대

### 경쟁 강도 판정

| Level | Indicator | Strategy |
|-------|-----------|----------|
| **블루오션** | 동일 업종 0-1개, 수요 존재 | 빠르게 진입, 선점 효과 |
| **적정 경쟁** | 2-3개 존재, 차별화 가능 | 명확한 포지셔닝 필수 |
| **과포화** | 5개 이상, 가격경쟁 중 | 압도적 차별화 없으면 진입 금지 |

## 5. 매출 가능성 분석 (Revenue Potential)

### 매출 추정 3가지 방법

| Method | Formula | Reliability |
|--------|---------|-------------|
| **유동인구 기반** | 유동인구 x 포착률(2-5%) x 객단가 | 중간 (포착률 가정 필요) |
| **좌석회전 기반** | 좌석수 x 회전율 x 객단가 x 영업일 | 높음 (실현 가능성 검증 용이) |
| **경쟁자 벤치마크** | 유사매장 추정매출 x 보정계수 | 높음 (실적 기반) |

### 매출 시나리오 분석

항상 3가지 시나리오로 제시:

| Scenario | Assumption | Use For |
|----------|-----------|---------|
| **보수적 (Conservative)** | 좌석회전 50% 수준, 배달 최소 | 최소 생존 가능성 판단 |
| **기본 (Base)** | 동종 업계 평균 수준 | 사업계획서 기준 |
| **낙관적 (Optimistic)** | 상위 20% 수준 달성 | 상한 가능성 (과신 경계) |

**판단 기준:** 보수적 시나리오에서 BEP 달성 불가능하면 사업 모델 재검토 필요.

## 6. 상권 성장성 (Commercial District Growth Potential)

### 성장성 지표

| Indicator | Positive Signal | Negative Signal |
|-----------|----------------|-----------------|
| **인구 변화** | 전입 > 전출, 세대수 증가 | 인구 감소, 고령화 심화 |
| **개발 호재** | 지하철 신설, 재개발, 대기업 입주 | 공장 이전, 기업 철수 |
| **임대료 추이** | 연 3-5% 안정적 상승 | 급등(>10%) 또는 하락 |
| **업종 다양성** | 새로운 업종 유입, 복합화 | 단일 업종 쏠림, 폐업 증가 |
| **유동인구 추이** | 전년 대비 증가 | 지속 감소 |
| **연령층 변화** | 2030 유입 증가 | 젊은층 이탈 |

### 상권 생명주기 판단

| Stage | Signal | 외식업 전략 |
|-------|--------|------------|
| **태동기** | 낮은 임대료, 예술가/스타트업 유입 | 선점 유리, 저투자 테스트 |
| **성장기** | 핫플화, 프랜차이즈 유입 시작, 임대료 상승 | 차별화 필수, 브랜드 구축 시기 |
| **전성기** | 주말 인파 최대, 높은 임대료, 대기업 브랜드 진출 | 높은 매출 가능하나 비용도 최대 |
| **쇠퇴기** | 핵심 브랜드 이탈, 공실 증가, 유동인구 감소 | 진입 금지, 기존 매장은 exit 검토 |

| **카테고리 순위** | 동네 배달 주문 비중 | 치킨 > 한식 > 중식 > 피자 > 분식 (전국 평균) |
| **평균 주문액** | 1건당 주문 금액 | 15,000-25,000원 |
| **리뷰 키워드** | 긍정/부정 핵심 단어 | "양 많음" "빠름" "포장 좋음" = 재주문 |
| **재주문율** | 단골 비율 | >30% = 강한 충성도 |

## 9. 타지 방문객 분석 (Visitor Analysis)

### 방문객 유형 분류

| Type | Behavior | F&B Preference |
|------|----------|----------------|
| **SNS 팔로워** | 인스타/유튜브에서 보고 방문 | 비주얼 중심, 대기 감수, 1회성 |
| **맛집 탐방객** | 블로그/TV 보고 목적 방문 | 맛 중심, 웨이팅 감수, 재방문 가능 |
| **쇼핑 연계** | 쇼핑/전시 후 식사 | 편의성 중시, 중간 가격대 |
| **외국인 관광객** | 한국 음식 경험 목적 | 한식 경험, 영어 메뉴, 사진 중요 |
| **비즈니스 방문** | 미팅/회의 후 식사 | 분위기, 접근성, 예약 가능 |

### 방문객 vs 주민 전략 밸런스

| 비중 | 전략 | 리스크 |
|------|------|--------|
| **방문객 >70%** | 높은 객단가, 비주얼, 화제성 | 유행 종료 시 매출 급락 |
| **주민 >70%** | 재방문율, 가성비, 편안함 | 성장 한계, 상권 변화에 취약 |
| **균형 (50:50)** | 가장 안정적, 이중 수요 | 두 그룹 모두 만족 어려움 |

**Best practice:** 주민 기반 60% + 방문객 40%가 가장 안정적인 매출 구조.

## 10. 종합 분석 리포트 구조

상권 분석 요청 시, 아래 구조로 종합 리포트를 작성:

```
## {동네명} 상권 소비자 분석 리포트

### 1. 상권 개요
- 위치 특성, 교통, 주요 시설
- 상권 유형 (오피스/주거/유흥/관광/복합)
- 상권 생명주기 단계

### 2. 유동인구 현황
- 일평균 유동인구 (출처 명시)
- 시간대별/요일별 분포
- 유동인구 품질 평가

### 3. 소비자 프로파일
- 주요 연령대 구성
- 소득 수준 추정
- 외식 빈도 및 객단가

### 4. 외식 트렌드 (최신)
- 해당 동네 인기 업종 TOP 5
- 최근 신규 오픈 트렌드
- 배달 인기 카테고리

### 5. 경쟁 환경
- 업종별 매장 수
- 핵심 경쟁자 (TOP 3-5)
- 포지셔닝 갭 (기회 영역)

### 6. 특수 수요
- 외국인 선호도
- 배달 수요
- 방문객 vs 주민 비중

### 7. 매출 가능성
- 3가지 시나리오 (보수/기본/낙관)
- 업종별 평균 매출 벤치마크

### 8. 성장성 전망
- 개발 호재/악재
- 인구 변화 추이
- 12개월 전망

### 9. 추천 업종 & 포지셔닝
- TOP 3 추천 업종 (근거 포함)
- 피해야 할 업종 (근거 포함)
- 차별화 방향

### 10. 다음 단계
- 현장 확인 사항
- 추가 데이터 수집 필요 사항
- 재분석 시점 권고
```

## 정보 업데이트 프로토콜 (Data Freshness Protocol)

### 자동 업데이트 트리거

분석 결과에 다음 안내를 항상 포함:

```
[데이터 기준일: YYYY-MM-DD]
[다음 업데이트 권고: 3개월 후 또는 아래 이벤트 발생 시]

업데이트 필요 시점:
- 해당 지역 대규모 개발 착공/완공
- 지하철/버스 노선 변경
- 대형 앵커 테넌트 입점/철수
- 계절 변경 (분기별 최소 1회)
- 경쟁 환경 급변 (신규 대형 매장 오픈)
```

```
변경사항: {새로운 정보가 있으면 기입}
같은 프레임워크로 최신 데이터 기반 재분석 부탁해."
```

## Interaction Rules (Coaching Mode)

When coaching is active for commercial district analysis topics, use these rules.

| Trigger | Action | Stop When |
|---------|--------|-----------|
| User asks for analysis without specifying neighborhood | Push: "어느 동네? 같은 구라도 블록마다 상권 특성이 완전히 다르다. 정확한 위치를 알려줘." | User specifies exact location |
| User relies on "느낌" without data | Challenge: "느낌은 데이터가 아니다. 소상공인진흥공단 상권분석 결과를 먼저 확인했어?" | User provides or requests data-based analysis |
| User ignores competition | Push: "반경 300m 내 동일 업종이 몇 개야? 경쟁 없는 장사는 없고, 과포화 상권에 진입하는 건 자살행위다." | User acknowledges competition landscape |
| User assumes current trend will last | Challenge: "그 트렌드 언제 시작됐어? 도입기/성장기/성숙기/쇠퇴기 중 지금 어디야?" | User considers lifecycle stage |

| User has answered 2 follow-ups on the same point | Stop pushing. Summarize gaps and deliver best-guess output. | -- |
