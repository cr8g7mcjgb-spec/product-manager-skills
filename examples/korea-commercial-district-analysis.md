# Example: Seongsu-dong Commercial District Consumer Analysis (성수동 상권 소비자 분석)

## Scenario

You are considering opening a restaurant in Seongsu-dong and want a comprehensive consumer analysis covering foot traffic, demographics, food trends, competitor landscape, delivery preferences, and foreign visitor patterns.

## Prompt

```text
성수동에서 외식업 창업하려고 해. 상권 소비자 분석 해줘. 유동인구, 연령대, 소비패턴, 경쟁매장, 매출 가능성, 성장성 전부 분석해줘. 외국인 선호도랑 배달 트렌드도 포함해줘.
```

## Example Output Excerpt

```text
성수동 상권 소비자 분석 리포트

[데이터 기준일: 2025-XX-XX]
[다음 업데이트 권고: 3개월 후]

1. 상권 개요
- 위치: 서울 성동구 성수동2가 (성수역 2호선 기준 도보 5분 반경)
- 상권 유형: 복합 상권 (오피스 + 핫플레이스 + 주거 혼합)
- 생명주기: 전성기 후반 → 안정기 진입 중. 임대료 상승 둔화 시그널 존재.
- 핵심 특성: 카페/베이커리 밀집, MZ세대 유입 강세, 주말 방문객 폭증

2. 유동인구 현황
- 일평균 유동인구: [최신 데이터 검색 결과 반영]
- 평일: 직장인 + 크리에이티브 종사자 중심
- 주말: 타지 방문객 300-500% 증가 (카페/갤러리/팝업 목적)
- 피크: 토요일 13:00-18:00 (평일 대비 3-5배)
- 품질: 체류형 유동인구 비중 높음 (소비 전환율 높음)

3. 소비자 프로파일
- 주요 연령: 25-39세 (전체의 60%+)
- 소득: 중상위 (IT/디자인/마케팅 종사자 밀집)
- 평균 외식 객단가: 15,000-25,000원 (카페 8,000-12,000원)
- 소비 특성: 경험 소비 선호, SNS 공유 활발, 새로운 것에 열려있음

4. 외식 트렌드 (최신)
- 인기 업종 TOP 5:
  1. 스페셜티 카페/베이커리
  2. 브런치/양식
  3. 일식 오마카세 (중저가)
  4. 비건/건강식
  5. 퓨전 한식
- 신규 오픈 트렌드: 작은 규모 전문점, 셰프 출신 캐주얼 다이닝
- 쇠퇴 중: 대형 프랜차이즈, 단순 치킨/피자

5. 경쟁 환경
- 카페: 과포화 (반경 300m 50개+). 진입 비추.
- 한식: 적정 (프리미엄 한식은 부족)
- 일식: 성장 중 (중저가 오마카세 인기, 아직 공간 있음)
- 양식/브런치: 포화 접근 중
- 포지셔닝 갭: 건강한 한식 + 비주얼 + 합리적 가격대

6. 외국인 선호도
- 주요 국적: 일본, 중국, 동남아, 서양 (성수동 카페 SNS 바이럴)
- 선호: 한식 경험 (비빔밥, BBQ, 전통찻집), 비주얼 카페
- 필수: 영어 메뉴, 사진 찍기 좋은 플레이팅
- 객단가: 한국인 대비 20-30% 높음 (경험 소비에 적극적)

7. 배달 선호도
- 성수동 배달 인기 TOP: 한식 도시락 > 샐러드/포케 > 일식 > 양식
- 점심 배달 수요 매우 높음 (주변 오피스 종사자)
- 평균 배달 주문액: 12,000-18,000원
- 특이점: 건강식/샐러드 배달 비중 타 지역 대비 2배

8. 매출 가능성 (20평 기준)
- 보수적: 월 2,500만원 (좌석회전 1.2회, 배달 20%)
- 기본: 월 3,500만원 (좌석회전 1.8회, 배달 30%)
- 낙관적: 월 5,000만원 (좌석회전 2.5회, 배달 35% + 주말 웨이팅)

9. 성장성 전망
- 긍정: 성수 전략정비구역 개발, 2호선 접근성 유지
- 부정: 임대료 상승 지속, 을지로/연남동으로 일부 수요 분산
- 전망: 안정적이나 폭발적 성장은 끝남. 체력전 국면.

10. 추천 업종
- 추천 1: 프리미엄 한정식/코스 한식 (외국인+MZ 모두 포용)
- 추천 2: 건강 도시락/포케 (배달 강세 + 오피스 수요)
- 추천 3: 디저트 전문 (소규모, 고마진, SNS 바이럴)
- 비추: 일반 카페, 대형 한식뷔페, 단순 프랜차이즈

다음 단계:
- 성수역 출구별 유동인구 현장 카운트 (토/일 포함)
- 관심 업종 경쟁자 5곳 직접 방문 및 분석
- 배달앱에서 해당 카테고리 상위 10개 매장 리뷰 분석
- 3개월 후 재분석 (임대료 동향 + 신규 오픈 매장 반영)
```

## What Good Looks Like

The analysis should:

- cover all 10 sections of the comprehensive report framework
- use latest data (clearly label data date and recommend next update)
- separate local resident preferences from visitor/tourist preferences
- include delivery-specific insights (not just dine-in)
- provide 3 revenue scenarios (conservative/base/optimistic)
- end with concrete next steps and re-analysis timing
- flag any data gaps honestly rather than guessing

## When to Push Back

If the user:
- asks for analysis without specifying exact location → demand specific neighborhood/block
- expects guaranteed success from trend data → remind that trends are lagging indicators
- ignores competition data → force competitor mapping before recommendations
